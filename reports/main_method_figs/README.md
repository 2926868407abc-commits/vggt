## 两组不要混着比

- **13-1 / 13-2 / 13-3** 对应文档里 ATE 0.2081 / 0.2205 / 0.0166 那张表（修复前训练）。
- **13.2-1 / 13.2-2 / 13.2-3** 对应等预算对照 4.38% / 63.52% / 12.91%（修复后训练）。

两组的训练渲染器不同，**组内可比，跨组不可比**。

## 一处必须说明的口径

**所有接触表都是现在渲染的，因此一律使用修复后的渲染器**，与该 run 训练时用的渲染器无关。

对 `13-1 / 13-2 / 13-3` 这三组（修复前训练）而言，图上会显示比训练时**更多**的 patch —— 训练时有 3/10 帧因四角出画被整块丢弃，现在那几帧会渲染出画面边缘的局部 patch。

这不是错误，是有意选择：图要展示 patch 的真实物理外观与摆放，而修复后的渲染器才是物理正确的。数值仍以各自训练时的渲染器为准。第 16 节正是解释这个差异的。

## 16 节那组怎么看

`16_render_fix_before_after/` 里是**同一张纹理**（`mid_accum4_s0_1000`）在两种渲染器下的对比，三个帧集各一对：

- `1_训练帧_修复前.png` / `1_训练帧_修复后.png`
- `2_TestA_修复前.png` / `2_TestA_修复后.png`
- `3_TestB_修复前.png` / `3_TestB_修复后.png`

看每帧标题里的 `cov=` 即可：修复前有若干帧是 `0.0000`（整块 patch 被丢弃），修复后同一帧变成画面边缘的局部 patch。
